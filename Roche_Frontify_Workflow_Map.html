2. Proposed unified workflow

One lifecycle for all 10 libraries. The workflow status records only where the asset is in its lifecycle. Content type, consent references and expiry dates move to metadata. Shades of blue mark work in progress, getting darker as the asset gets closer to release. Hover over a status for its entry and exit criteria.

3. Migration map

Where each current status label goes in the unified model. Line thickness shows how many libraries use the label. Dashed, faded lines are statuses that are empty everywhere, so they can be deleted without moving any assets. Hover over a label or a line to see the action needed.

Source: Frontify API (workflow statuses for each library, plus an asset search for each status to check whether it holds assets). The results only include assets visible to the account that ran the scan. The API does not return asset counts, so this map shows whether a status is used, not how many assets it holds.
