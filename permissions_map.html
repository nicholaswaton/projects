Frontify library permissions map: user groups

⚠ Group access is inferred, and folder-level permissions are not available The Frontify API lists only each library's effective users, not which groups were granted access. A group counts as granted a role when at least of its members hold that role or higher in the library. The API also has no permission fields on folders, so every folder is shown as inheriting its library's access. Folder-level restrictions set in the Frontify UI are not reflected here. Collaborators per library and role

The number of users holding each role in each library, including access through groups. Cell shading uses a log scale (1 / 10 / 100 / 1K / 10K+). "Individual (est.)" counts users whose role is not explained by any of their groups.

Group access by library

The inferred role of each user group in each library. "Implied" grants belong to groups whose members are almost all in a broader group with the same or higher role, so the access most likely comes from that broader group. Hover over a cell to see the evidence.

Folder map

Each library's folder tree. Every folder inherits the access of its library: the groups shown on the root row. The asset count is the number of assets directly in that folder.
